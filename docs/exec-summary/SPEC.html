Billing record

Record income and spending from a photo of a bank slip or receipt, and see it as pie charts.

The goal

A personal web app that records your income and spending in Thai baht. You upload a photo of a bank slip or a receipt, the app reads it and fills in a form, and you check it and save.

You can also type a record in by hand. A dashboard shows pie charts of where money came from and where it went, for a month you choose.

It is for one person (you) and is used for a live demo. It is a prototype that should take about 2-3 hours to build.

Rules the AI follows

Always

  • Run the lint, type and test checks before each commit.
  • Check all inputs.
  • Store money as whole satang.
  • Keep secrets in the private settings file only.
  • Check for secrets before every push, because the repository is public.

Asks you first

  • Adding tools that are not in the tech stack.
  • Changing the data model after the first migration.
  • Any use of Claude credits beyond the manual demo check.
  • Deploying anywhere.
  • Changing the category list.

Never

  • Commit private settings, the database folder, temporary files, handoff notes or node_modules.
  • Call the real Claude service in automatic tests.
  • Log full images or the API key.
  • Save a record without you pressing Save.

How it will be checked

Automatic tests cover the money maths, the AI answer checking and the login cookie, using a pretend AI so no credits are spent.

One end-to-end test logs in, adds an expense by hand and checks it shows in the pie chart.

Before the demo you upload 3 real images (a Thai bank slip, a receipt and an unreadable image) and check the result by eye. There is no coverage target.
